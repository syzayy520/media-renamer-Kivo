## 三、需要用户确认的问题（阻塞项）

以下问题需要在进入阶段 1 前由用户确认（高优先级）：

### HIGH — 阻塞问题

1. **[命名-001]** 电影文件名不含年份时，如何处理？
   - 选项 A：标记为低置信度，进入人工确认
   - 选项 B：尝试从父目录名推断年份
   - 推荐默认：**选项 A**（安全优先）

2. **[命名-002]** 多集文件（如 `S01E01-E02`）如何处理？
   - 选项 A：拆分为两个独立文件处理（需要硬链接或复制策略讨论）
   - 选项 B：改名但保留 E01-E02 格式
   - 推荐默认：**选项 B**（不改文件数量关系，只改命名）

3. **[命名-003]** 目标路径重名冲突时如何处理？
   - 选项 A：自动加数字后缀（`_1`、`_2`）
   - 选项 B：标记为冲突，阻断执行，等待人工处理
   - 推荐默认：**选项 B**（安全优先，不允许自动覆盖或静默改名）

4. **[范围-001]** 单次扫描递归策略？
   - 推荐默认：**默认递归扫描子目录，但必须有进度反馈、取消机制、权限失败记录、最大文件数量保护、符号链接/循环路径处理策略**

5. **[范围-002]** 网络路径策略？
   - 推荐默认：**MVP 不主动发现 NAS/SMB，不做远程账号登录；但系统已挂载的网络路径按普通路径处理，并必须处理断连、权限失败、路径不可达**

### MEDIUM — 建议确认

6. **[UI-001]** UI 主题策略？
   - 推荐默认：**MVP 默认中文界面；主题在阶段 3 UI/UX 阶段比较浅色、深色、跟随系统三种方案后再确定**

7. **[UI-002]** MVP 界面语言？
   - 推荐默认：**中文界面**（目标用户群主要为中文用户）

8. **[规模-001]** 文件量目标？
   - 推荐默认：**MVP 稳定处理 10,000 个视频文件，架构设计目标不低于 100,000 文件，UI 必须考虑虚拟滚动或分页**
