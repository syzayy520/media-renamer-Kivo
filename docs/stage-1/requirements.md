# 需求规格定义

> 阶段 1：需求规格定义
> 项目：media-renamer-Kivo
> 日期：2026-06-08

---

## 一、项目目标

构建一个 Windows 桌面应用，用于扫描本地媒体目录中的视频文件，通过解析文件名提取元信息（标题、年份、季集号、分辨率、编码、音轨等），按可配置命名模板生成规范化重命名预览，经用户人工确认后安全执行改名，并记录完整审计日志，支持按任务回滚。

**核心价值**：将媒体库中混乱的文件名批量整理为统一规范格式，以极高安全性避免误操作。

### MVP 包含

| ID | 功能域 | 说明 |
|----|--------|------|
| F-001 | 媒体扫描 | 扫描指定目录（递归），识别 13 种视频文件 |
| F-002 | 文件名解析 | 从文件名提取标题、年份、季集、分辨率、来源、编码、音轨等信息 |
| F-003 | 分类识别 | 区分电影、电视剧、动漫、特别篇、SP、OVA、NCOP、NCED、Extras |

| F-011 | 人工确认 | 低置信度项需人工审核、修改解析结果 |

## 四、用户角色

### 主要用户

| 角色 | 特征 | 使用场景 |
|------|------|----------|
| 媒体收藏者 | 拥有 100-10,000+ 视频文件，使用 Plex/Jellyfin/Emby/Kodi | 下载后批量整理文件名 |
| PT 用户 | 从 PT 站下载，文件名含组名、标签 | 去除组名标记，统一格式 |
| 数字化收藏者 | 翻录蓝光/DVD，自定义文件名 | 统一命名格式 |

### 用户技术水平

- 主要：有一定技术基础，了解媒体文件命名规范
- 次要：普通用户，需要清晰的操作指引

---

## 五、核心用户流程

```
1. 启动应用
2. 选择媒体目录
3. 点击"扫描"
4. 等待扫描完成（显示进度）
5. 查看扫描结果统计
6. 筛选/搜索文件
7. 查看重命名预览
8. 审核低置信度项
9. 处理冲突项
10. 确认执行
11. 查看执行结果
12. （可选）回滚
```

### 6.11 命名模板（F-012）

**电影默认模板**：
```
{Title} ({Year}) [{Resolution} {Source} {VideoCodec} {AudioCodec}].{ext}
```

**剧集默认模板**：
```
{SeriesTitle} - S{Season:02}E{Episode:02} - {EpisodeTitle}.{ext}
```
无 EpisodeTitle 时：
```
{SeriesTitle} - S{Season:02}E{Episode:02}.{ext}
```

**动漫默认模板**：
```
{SeriesTitle} - S{Season:02}E{Episode:02} [{Group}][{Resolution}].{ext}
```

**特别篇/OVA/SP 默认模板**：
```
{SeriesTitle} - S00E{SpecialNumber:02} - {SpecialTitle}.{ext}
```

**NCOP/NCED/Extras 默认模板**：
```
{SeriesTitle} - Extra - {ExtraType}{ExtraNumber}.{ext}
```

**多集格式**：
```
{SeriesTitle} - S{Season:02}E{EpisodeStart:02}-E{EpisodeEnd:02}.{ext}
```

### 8.2 核心 UX 原则

1. 安全感优先：用户始终清楚软件在做什么
2. 可控感：每个操作都有预览和确认
3. 信息清晰：原路径 vs 新名称对比一目了然
4. 风险可视：低置信度、冲突项醒目标记
5. 危险操作明确：执行按钮有明确语义
6. 操作路径清楚：用户知道下一步做什么
7. 状态反馈完整：每个操作都有明确结果
8. 大批量好用：虚拟滚动、筛选、排序

| 空目录 | 显示空状态提示 |
| 无视频文件 | 显示无视频提示 |
| 文件名极短（<3字符） | 标记低置信度 |
| 文件名极长（>200字符） | 标记路径过长风险 |
| 含非 UTF-8 编码 | 尝试编码检测，异常标记 |
| 符号链接 | 检测并标记 |
| 循环路径 | 检测并跳过 |
| 网络路径断连 | 记录错误并继续 |
| 权限不足 | 记录并跳过 |
| 最大文件数量 | 达到上限时停止扫描并提示 |

---

## 十二、错误场景

| 场景 | 处理 |
|------|------|
| 扫描中途失败 | 记录已扫描文件，提示用户 |
| 改名失败（权限） | 记录失败，继续其他文件 |
| 改名失败（文件被占用） | 记录失败，继续其他文件 |
| 改名失败（路径不存在） | 记录失败，继续其他文件 |
| 回滚失败（目标文件不存在） | 暂停回滚，报告失败项 |
| 回滚失败（原路径被占用） | 暂停回滚，报告失败项 |
| 应用崩溃 | 启动时检查未完成任务 |

## 十三、风险场景

| 风险 | 缓解 |
|------|------|
| 误改名 | dry-run + 多重检测 + 二次确认 + 审计 + 回滚 |
| 回滚失败 | 回滚前检测 + 冲突报告 + 部分回滚 |
| 路径过长 | 扫描阶段检测 + 预览标记 |
| 整树家谱腐化 | 每轮审计 + BLOCKED 机制 |

## 十五、安全要求

1. 默认 dry-run
2. 执行前 10 项安全检查
3. 低置信度强制人工确认
4. 冲突项阻断执行
5. 二次确认机制
6. 完整 before/after 审计
7. 支持按任务回滚

## 十六、回滚要求

1. 基于 before/after 映射

3. 冲突时暂停报告
4. 部分回滚支持
5. 回滚本身记录审计
6. 持久化回滚记录

## 十七、审计日志要求

4. 持久化到本地数据库
5. 支持 JSONL 导出
6. 不可篡改
