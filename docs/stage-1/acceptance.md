# 验收标准

> 阶段 1：需求规格定义
> 项目：media-renamer-Kivo
> 日期：2026-06-08

---

## 一、验收维度

| 维度 | 权重 |
|------|:----:|
| 功能完整性 | 30% |
| 安全性 | 25% |
| 回滚可靠性 | 15% |
| 性能 | 10% |
| UI/UX | 10% |

## 二、验收条件

### 功能验收（必须）

- A-FUNC-001: 扫描目录识别视频文件
- A-FUNC-002: 递归扫描子目录
- A-FUNC-003: 扫描进度/取消
- A-FUNC-004: 文件名解析（标题/年份/季集/分辨率/编码）
- A-FUNC-005: 分类识别（电影/剧集/动漫/特别篇/未识别）
- A-FUNC-006: 按模板生成新文件名
- A-FUNC-007: before/after 对比展示
- A-FUNC-008: 低置信度标记和人工确认
- A-FUNC-009: 冲突检测（重名/路径长度/非法字符）
- A-FUNC-010: dry-run 预览
- A-FUNC-011: 二次确认执行
- A-FUNC-012: 审计日志记录
- A-FUNC-013: 按任务回滚
- A-FUNC-014: 任务历史查看
- A-FUNC-015: TMDb API Key 配置入口（设置页）
- A-FUNC-016: TMDb API Key 保存/更新/清除功能
- A-FUNC-017: TMDb API Key 遮罩显示
- A-FUNC-018: TMDb API Key 测试连接入口
- A-FUNC-019: 未配置 TMDb Key 时显示提示信息
- A-FUNC-020: TMDb 功能不阻塞本地规则重命名主流程

### 安全验收（必须）

- A-SEC-001: 默认 dry-run
- A-SEC-002: 低置信度不自动执行
- A-SEC-003: 冲突项阻断执行
- A-SEC-004: 执行前二次确认
- A-SEC-005: 不自动覆盖/追加后缀
- A-SEC-006: 测试 sandbox 隔离
- A-SEC-007: TMDb API Key 不得出现在日志、审计日志、控制台、导出文件中
- A-SEC-008: TMDb API Key 不得被提交进仓库
- A-SEC-009: UI 中不得明文长期展示完整 TMDb API Key

### 回滚验收（必须）

- A-ROLL-001: 按任务回滚
- A-ROLL-002: 回滚前文件状态检测
- A-ROLL-003: 冲突暂停报告
- A-ROLL-004: 回滚记录持久化
- A-ROLL-005: 回滚记录审计

### 性能验收

- A-PERF-001: 10,000 文件扫描 < 30 秒
- A-PERF-002: UI 虚拟滚动流畅
- A-PERF-003: 启动 < 3 秒
- A-PERF-004: 内存 < 500MB (10,000 文件)

## 三、失败条件

以下任一条件满足，验收失败：

1. 误改名（未经过预览确认就执行）
2. 低置信度项自动执行
3. 冲突项未阻断
4. 回滚失败且无法恢复
5. 审计日志丢失
6. 整树家谱模式严重违反
7. 核心流程测试不通过
8. TMDb API Key 出现在日志、审计日志、控制台、导出文件中
9. TMDb API Key 被提交进仓库
10. 未配置 TMDb Key 时，本地扫描/预览/改名/回滚功能不可用
11. 配置 TMDb Key 后，设置页无法显示已配置状态
12. 清除 TMDb Key 后，系统继续使用旧 Key

---

## 四、停止条件

以下情况必须停止并修复：

1. 发现误改名风险
2. 回滚不可靠
3. 性能远低于目标
4. UI 审美不达标
5. 结构腐化

---

## 五、不允许交付的情况

1. 未通过安全验收
2. 回滚不可靠
3. 核心测试不通过
4. 整树家谱模式被破坏
5. 审计日志不完整

---

## 六、UI 验收标准

- 页面结构清晰
- 操作路径明确
- 危险操作语义明确
- 状态反馈完整
- 空状态有提示
- 加载状态有反馈
- 错误状态有提示
- 大列表虚拟滚动
- 专业桌面工具气质
- 无廉价感

---

## 七、安全验收标准

- 10 项安全检查全部通过
- 默认 dry-run 不可关闭
- 低置信度强制人工确认
- 冲突项阻断执行
- 二次确认机制生效

---

## 八、回滚验收标准

- 100% 成功改名可回滚
- 回滚前检测文件状态
- 冲突暂停报告
- 持久化回滚记录
- 回滚本身有审计

---

## 九、结构验收标准

- 每个文件单职责
- 入口文件 ≤30 行
- 无万能 utils
- 无上帝 service
- 无 flat helper

---

## 十、整树家谱验收标准

- module-genealogy.md 完整
- 测试镜像模块树
- traceability-matrix.md 完整
- 新增文件有明确所属功能族
