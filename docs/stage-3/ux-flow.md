## 详细流程

### 1. 扫描流程

```
用户点击"选择目录"
    ↓
系统打开目录选择对话框
    ↓
用户选择目录
    ↓
用户点击"开始扫描"
    ↓
系统开始扫描（显示进度条）
    ↓
扫描完成 → 显示统计信息
    ↓
用户点击"查看预览"
```

### 2. 预览流程

```
系统生成预览列表
    ↓
用户查看 before/after 对比
    ↓
用户筛选：电影/剧集/动漫/特别篇/未识别
    ↓
用户筛选：低置信度/冲突
    ↓
用户排序：状态/置信度/文件名
    ↓
用户批量选中/取消选中
    ↓
用户点击"处理低置信度项"
    ↓
进入人工确认流程
```

### 3. 人工确认流程

```
系统显示低置信度项列表
    ↓
用户逐项审核：
  - 修改类型
  - 修改标题
  - 修改年份
  - 修改季集
  - 标记跳过
    ↓
用户点击"保存确认"
    ↓
返回预览页
```

### 4. 执行确认流程

```
系统显示执行统计：
  - 总数量
  - 将改名数量
  - 跳过数量
  - 冲突数量
  - 低置信度数量
    ↓
系统明确提示："真实文件名将被修改"
    ↓
用户点击"确认执行"
    ↓
系统执行改名（显示进度）
    ↓
系统显示执行结果
```

### 5. 回滚流程

```
用户在历史页选择任务
    ↓
用户点击"回滚"
    ↓
系统显示回滚确认
    ↓
用户确认回滚
    ↓
系统执行回滚（显示进度）
    ↓
系统显示回滚结果
```

## 状态页面

| 状态 | 页面 | 反馈 |
|------|------|------|
| 空状态 | 扫描页 | "请选择媒体目录开始扫描" |
| 扫描中 | 扫描页 | 进度条 + 文件计数 |
| 扫描完成 | 预览页 | 分类统计 |
| 低置信度 | 人工确认页 | 黄色警告标签 |
| 冲突 | 预览页 | 红色冲突标签 |
| 执行中 | 执行确认页 | 进度条 |
| 部分失败 | 执行确认页 | 失败项列表 |
| 回滚成功 | 历史页 | 绿色成功标签 |
| 回滚失败 | 历史页 | 红色失败标签 |
