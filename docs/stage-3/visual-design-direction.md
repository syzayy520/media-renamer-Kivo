# 视觉设计方向

> 阶段 3：系统架构设计
> 项目：media-renamer-Kivo
> 日期：2026-06-08

---

## 设计原则

1. **安全感优先**：用户始终清楚软件在做什么
2. **可控感**：每个操作都有预览和确认
3. **信息清晰**：对比一目了然
4. **风险可视**：风险项醒目标记
5. **审美克制**：专业桌面工具气质

---

## 主题方案

**决策**：阶段 3 比较三种方案后，选择**深色主题**作为 MVP 默认。

**理由**：
1. 专业工具标准（VS Code、Figma、DaVinci Resolve 均默认深色）
2. 长时间使用减少视觉疲劳
3. 风险标记在深色背景上更醒目
4. 与媒体库软件气质相符

**预留**：后续可通过 CSS 变量支持浅色主题。
